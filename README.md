# ai-product-journey

一个非技术背景的人，用 84 天从零学做 AI 产品的完整记录。

## 这个项目是什么

我在执行一份为期 12 周的自学计划，目标是成为「懂技术又懂产品」的人，能自己把 AI 产品做出来并推向用户。
起点是接近零基础的编程水平（8 年前写过一点 JavaScript，基本忘光了）。

这个仓库存放整个过程的所有代码、笔记和产出物。

- **计划周期**：2026-10-19 ~ 2027-01-10
- **每日投入**：1 小时
- **工作方式**：vibe coding —— 代码主要由 AI 生成，我负责读懂、验收、调试和架构决策

## 如何运行

```bash
# 1. 安装 uv（Python 环境管理工具）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 创建虚拟环境并安装依赖
uv venv --python 3.12
uv pip install --python .venv/bin/python -r requirements.txt

# 3. 运行第一个程序
.venv/bin/python day_counter.py
```

## 目录结构

## 我遵循的纪律

1. AI 写的每一行代码，我都要能解释。解释不了就让它讲到我懂为止。
2. 每次改动前先 commit。Git 是安全网。
3. 先要方案，再要代码。
4. 小步走，每步都验证。
5. 每周必须有能运行的东西，不是笔记，是能点的。
